# TAEGEOM Digital Training System v1.1

태권검도 수련생이 혼자 반복수련하고, 검선·반응·정확도·수련시간·점수를 기록할 수 있도록 만든 웹 기반 디지털 트레이닝 프로그램입니다.

## v1.1 주요 업그레이드

- 정면베기 3종 분리: 초승달 / 반달 / 보름달
- 각 기술별 서로 다른 검선과 실제 검 애니메이션
- 좌·우베기 15° 분리
- 사선 내려베기·올려베기 좌우 65° 분리
- 찌르기 / 얼굴막기 / 몸통막기 / 아래막기
- 3·2·1 카운트다운 + 삐 소리 + 랜덤 공격 대응 선택
- 반응속도 자동 측정
- 3연속 콤보 훈련
- 초급/중급/고급 검선 표시 강도
- 세션 점수·정확도·횟수·시간·최고 반응 기록
- 오늘 목표 100회 및 브라우저 LocalStorage 누적 기록
- JSON 기록 내보내기
- 키보드 단축키: Space 시작/종료, ↑ 정확 수행, ↓ 실수

## GitHub Pages 업로드

저장소 최상위(root)에 아래 4개 파일을 올립니다.

- `index.html`
- `style.css`
- `app.js`
- `README.md`

그 후 Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
