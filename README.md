# TAEGEOM Digital Training System v1.6 — INTEGRATED ACADEMY

## 핵심 원칙
v1.6은 **v1.4의 실제 디지털 수련 기능을 삭제하지 않고 그대로 보존**하면서,
v1.5에서 설계한 Academy 교육구조를 별도 페이지로 통합한 누적 개발 버전입니다.

## 그대로 살아있는 실제 수련 기능
- 초승달·반달·보름달베기
- 측면 준비각도 비교 가이드
- 좌·우 15° 베기
- 사선 내려/올려베기 65°
- 찌르기
- 얼굴막기·몸통막기·아래막기
- 3·2·1 랜덤 반응훈련
- 콤보훈련
- 검선 난이도
- 수행횟수·정확도·점수·누적 수련시간
- Daily Mission
- 기술별 합격기준
- Training XP / Level 1–10
- 디지털 수련 인증카드
- 브라우저 자동 기록

## 새롭게 통합된 Academy
