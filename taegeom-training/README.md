# TAEGEOM Training System

태권검도 수련생이 혼자서 반복 수련하고, 수행 횟수·정확도·점수·수련시간을 기록할 수 있도록 만든 웹 기반 디지털 트레이닝 프로그램입니다.

## 추천 GitHub 저장소 이름
`taegeom-training`

## 현재 포함 기능
- 정면베기
- 좌·우 15도 베기
- 사선 내려·올려베기 65도
- 찌르기
- 얼굴막기·몸통막기·아래막기 훈련
- 3·2·1 반응 훈련
- 콤보 훈련
- 초급·중급·고급 검선 표시
- 수행횟수·정확도·점수·수련시간 기록
- 브라우저 LocalStorage 자동 저장
- 기록 JSON 파일 내보내기
- 모바일 대응 반응형 화면

## GitHub Pages 올리는 방법
1. GitHub에서 새 저장소를 만듭니다.
2. 저장소 이름을 `taegeom-training` 으로 권장합니다.
3. ZIP 압축을 풀고 `index.html`, `style.css`, `app.js`, `README.md` 파일을 저장소 최상위에 업로드합니다.
4. GitHub 저장소의 Settings → Pages 로 이동합니다.
5. Deploy from a branch → main / root 를 선택하고 저장합니다.
6. 잠시 후 공개 주소가 생성됩니다.
